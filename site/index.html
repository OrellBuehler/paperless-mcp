paperless-mcp connects Claude and any other MCP client to your Paperless-ngx archive. Search, upload, tag, split and share documents in plain language, with optional semantic search across everything you have ever scanned.

Everything Paperless can do, through conversation

Not a thin search wrapper. paperless-mcp covers documents, metadata, permissions, mail, workflows and system administration, and adds tools built for agents on top.

Full document management

Search, upload, download, update and bulk-edit documents. Manage tags, correspondents, document types, storage paths, custom fields and saved views.

Semantic search

Find documents by meaning, not keywords. Embeddings from OpenAI or Ollama, stored locally in sqlite-vec. No external vector database.

AI-assisted workflows

Auto-classify documents, triage the inbox, bulk-tag by content, and spot missing recurring documents year over year, for example when preparing taxes.

PDF page tools

Pull out just the page that matters as a new PDF, or find which pages mention a phrase. Processed locally, without touching the original.

Multi-user and OAuth

Run one HTTP server for the whole household or team. Every request runs as the signed-in user, with their own Paperless permissions. Optional OIDC sign-in.

Mail, sharing and trash

Configure mail accounts and rules, create public share links and bundles, email documents, and restore from the trash.

Paperless-ngx 3.0 ready

Document versions, PDF editing, share bundles and task management. The REST API version is pinned so 2.x and 3.x servers behave the same.

Safe by design

Read, create and update for configuration objects; no silent deletes of views, users or workflows. Origin and host allowlists for the HTTP transport.

Docker sidecar

Prebuilt image on GHCR. Drop it next to Paperless in your compose stack and point your clients at /mcp.

Ask, don't click

Things you can say once it's connected.

“Find all invoices from my ISP in 2025 and tag them as telecom.”
“Upload this PDF, set the correspondent to my landlord, and file it as a contract.”
“Which documents in my inbox are missing a correspondent or document type?”
“Give me just the page of my insurance policy that mentions the deductible.”
“Which bank statements from last year are missing compared to this year?”
“Find the document about the espresso machine warranty.” Semantic search: no keyword match needed.

Run it your way

Start with one command on your laptop, or run a shared server next to Paperless.

stdio, single user

Your MCP client launches the server via npx. Nothing to host.

  • Claude Code, Claude Desktop, any MCP client
  • Uses your Paperless API token
  • Semantic index stored in ~/.paperless-mcp
{
  "mcpServers": {
    "paperless": {
      "command": "npx",
      "args": ["-y", "@orellbuehler/paperless-mcp"],
      "env": {
        "PAPERLESS_URL": "https://paperless.example.com",
        "PAPERLESS_TOKEN": "your-api-token"
      }
    }
  }
}

HTTP sidecar, multi-user

One server for everyone. Each request runs with the caller's own token.

  • Prebuilt Docker image on GHCR
  • Optional OAuth sign-in via your Paperless OIDC provider
  • Shared semantic index, filtered per user
paperless-mcp:
  image: ghcr.io/orellbuehler/paperless-mcp:latest
  ports: ["3001:3001"]
  volumes: ["./mcp:/data"]
  environment:
    PAPERLESS_URL: http://webserver:8000
    PAPERLESS_TOKEN: <admin-token>

Compatibility

The client pins REST API v9 by default, so behavior doesn't change when you upgrade Paperless. Opt into v10 with PAPERLESS_API_VERSION=10.
